# 💜 RUPSHA — Your Playful AI Companion

[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/Mickey-11-sys/rupsha-ai/blob/main/RUPSHA_Launcher.ipynb)

A warm, witty, and intelligent AI assistant built from scratch with Python, Groq API, and Gradio.

## ✨ Features
- 💬 Dual-Mode Chat (Companion + Work mode)
- 🧠 Persistent Memory
- 🔧 Tool Use (Web Search, Calculator)
- 🎭 Emotion-Aware Responses

## 🚀 Quick Start
Click the **"Open in Colab"** badge above ↑ and run all cells!

## 🛠️ Tech Stack
- **LLM**: Groq API (GPT-OSS-120B)
- **UI**: Gradio
- **Memory**: SQLite
